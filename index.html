gdrive-backup

A personal, single-user backup tool that copies restic-encrypted backups from a private homelab server to the operator's own Google Drive account.

What this app does

gdrive-backup runs on the operator's TrueNAS server and uses rclone to upload restic backup repositories to a folder in Google Drive. It runs on a daily schedule and keeps an encrypted off-site copy of the homelab backups.

Who can use it

This is not a public service. There is no sign-up, no login, and no user accounts. The only person who authorizes the app is the account owner, and the app only accesses that owner's Google Drive.

Google Drive access

The app requests the drive.file OAuth scope. That scope only allows it to create and manage files that it created itself; it cannot see or read any other files in the Google Account. Access can be revoked at any time from the Google Account permissions page.

Data handling

  • Backups are encrypted by restic on the server before upload. Google only stores encrypted data.
  • This website sets no cookies, runs no analytics, and collects no personal data.
  • No Google user data is sold, shared, or used for advertising.
